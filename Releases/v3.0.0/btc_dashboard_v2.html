Methodology & badge rules
  • Rows: the 12 completed calendar months plus the current partial month. Historical cells use the last valid observation within the month (monthly M2: that month's observation). The current row shows each metric's latest published observation, with its own date.
  • NLM 8W Δ: change over 8 weeks in net liquidity = WALCL/1e6 − WDTGAL/1e6 − RRPONTSYD/1,000 ($T), with all three on the same Wednesday. If any input is missing for that Wednesday (e.g. a holiday), the value is unavailable and is not carried forward. This is an analytical proxy, not a proven lead indicator.
  • Bullish: M2 3-month change > +0.1% · NLM > +0.1T · RRP < $500B · TGA < $600B · Real yield < 1.5% · WALCL 13-week change > 0
  • Bearish: M2 < −0.1% · NLM < −0.1T · RRP > $1,000B · TGA > $800B · Real yield > 2.5% · WALCL < −3%. Neutral: in between.
  • L1 Signal: Bullish if ≥4 of 6 bullish; Bearish if ≥3 bearish; otherwise Neutral. If missing inputs could change the result, it shows Insufficient data. L1 score: bull 2 / neutral 1 / bear 0 points averaged over available inputs (needs ≥4).
  • Historical values are FRED's latest revised observations, not real-time vintages. Use ALFRED for backtests. Click any value to see its source.
Sources: FRED series M2SL, WALCL, WDTGAL, RRPONTSYD, DFII10. Manual Set values apply to the current row only and are marked ✎.
